# calas-site — CLAUDE.md

calasautomations.com marketing site (GitHub Pages, static HTML/CSS/JS).

## Stack
- Static HTML pages, no build step
- CSS: `calas-ui.css` (base) → `calas-editorial.css` (editorial pages) → `calas-theme.css` (shared uplift for all other pages)
- Fonts: Libre Baskerville (headings), IBM Plex Sans (body)
- Colors: navy `#0B2E45` (hero bg), gold `#F0C171` (accents), ink `#1A1A2E`

## House rules
- Gold `<em>` on hero h1 on every page — never skip this
- No "Book 15 minutes" copy anywhere — replaced with self-serve messaging
- The spinning crest logo is real SVG, never rasterize it
- Do NOT change prices or Stripe links without explicit approval
- Deploy path: push to `main` → GitHub Pages auto-publishes

## Pages
`/` index, `/pay` pricing, `/guardian` Watchpost Guardian, `/haul-me`, `/lead-me`, `/quote-me`, `/dispatchme`, `/receiptsort`, `/accounting`, `/file` (On File)
