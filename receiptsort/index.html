How it works

Three steps, no setup.

STEP 01

Drop the receipts in.

Phone photos, scanner output, emailed PDFs. Put them in a folder and point ReceiptSort at it.

STEP 02

It reads them.

Date, vendor, total, and tax where it can find it. On your own machine — the files never leave it.

How to run it

Download, unzip, run.

STEP 01

Download and unzip.

ReceiptSort.zip — unzip it anywhere on your computer.

STEP 02

You need Python 3.11 or newer.

Once, in a terminal: pip install markitdown pytesseract Pillow. To read photos, also install Tesseract OCR (free, offline). PDFs with a text layer work without it.

STEP 03

Start it.

Double-click run.bat (Windows), or run python receiptsort.py --web from the unzipped folder.

No network calls, ever — the only optional connection is to a model running on your own computer (Ollama at 127.0.0.1); pass --no-llm to disable even that.

Needs review

It will get some wrong, and it will tell you which.

Faded thermal paper, a crumpled photo taken in a truck, a receipt with three totals on it — when ReceiptSort isn't sure, the row is marked needs_review instead of quietly filled in. Check those rows against the originals. It's a sorter, not a bookkeeper, and it doesn't pretend to be.
